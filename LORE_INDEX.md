# DRAKENHOLD — LORE INDEX

*A register of every engraving, map, note, document, book and inscribed surface in the module **that connects to something else.** Not everything written on a wall in Drakenhold is here; a thing earns a row by having a far end.*

---

## WHAT THIS FILE IS, AND WHAT IT IS NOT

**This is an index. It is not a source.** The text of every item lives in its region file, which stays authoritative. This file carries a pointer and a one-line gist and nothing more.

That restriction is the whole design. `HANDOFF.md` records what happened the last time a tracking file was allowed to hold content: it became a fourth place the truth lived, and it drifted. **A pass that finds this file disagreeing with a region file fixes this file.** A row that starts to read like the item itself is over-written and is cut back.

**What a row is for.** The documentary layer of this module is a network — a ledger at one end of the road answers a ledger at the other, a scratched name under a bench answers a name absent from official carving three regions away. That network is the single most drift-prone thing in the project, and `OPEN_QUESTIONS.md` already carries one instance of it going wrong in a block document. A far end that is checked at both ends is checked here first.

**Registers.** `P` player-facing — the item is described in a Player's Overview and may be read at the table as written. `R` referee-facing — the item's contents are the Referee's, conveyed rather than read out.

**Status.** `written` — the region's step-9 outline holds the detail. `stubbed` — a step-7 working note names it and the detail is not written. `proposed` — offered by a pass and not yet placed in a region file.

## OPEN FAR ENDS

*Rows above whose far end is named but not yet written. Each is the owning region's to close, and none may be closed by assumption.*

- **`FC.19`'s fleeing Guild contact.** The stones name where he was going. Nowhere in the module is that destination written. `FC`'s pass owns it.
- **`B.11`'s Thurgan and Azost.** Two places, far north, confirmed by the ledger and by nothing else. Deliberately outside the module.
- **The Kelmor citation.** `PEAK_3_BLOCK` cites `HB.7`; `HB`'s own stub puts the Guild gallery at `HB.8`. Documented and unresolved in `OPEN_QUESTIONS.md`; `HB` owns both the correction and the alternative.
- **Torvin Ganthur's name.** Present in graffiti and ledgers, absent from all official carving, and it opens `HB`'s interment. The chain runs `GB.9` → `HB` and is the module's longest documentary thread.
